# Discovery testing workspace guide

This directory documents the reusable discovery tooling. The executable harnesses were developed and run outside the application source at:

`C:\Users\infor\AppData\Local\Temp\opencode\discovery-workspace`

## Files

- `run_isolated.py` — disposable Flask launcher with side-effect blockers.
- `make_synthetic_data.py` — writes synthetic `app-copy/data.json` with valid theme IDs.
- `cdp_tests.js` — final Chrome DevTools Protocol live-browser harness.
- `discovery_tests.py` — original Playwright harness; not executable in this environment because Playwright installation failed.
- `app-copy/` — disposable copy of application code/templates/static assets in the temp workspace, not in the repository.
- `venv/` — application dependency environment in the temp workspace.
- `pw-venv/` — Playwright tooling environment in the temp workspace; contains only pip/setuptools.

The original Playwright sequence was attempted and is recorded in `../evidence/logs/playwright_install_failure.md` and `playwright-retry.log`; it is not the live evidence source.

## Safety controls

- `DATABASE_URL` forced to `app-copy/discovery.db`.
- Loopback-only bind at `127.0.0.1:5001`.
- Scheduler disabled before import.
- `requests.post` and `smtplib.SMTP` blocked.
- Notification helpers patched to no-ops.
- Fresh disposable Chrome profile per run; JavaScript confirms auto-accepted.
- No production credentials, database, uploads, or templates used.
